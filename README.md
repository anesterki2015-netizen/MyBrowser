# MyBrowser

**MyBrowser** is a simple, fast desktop web browser built with **Electron**.

## Download

[⬇️ Download MyBrowser 1.0.0](https://github.com/anesterki2015-netizen/MyBrowser/releases/download/v1.0.0/MyBrowser-1.0.0-Setup.1.exe)

## Features

* 🌐 Web browsing
* ⚡ Simple and fast interface
* 🖥️ Desktop application
* 🔖 Quick links to popular websites
* 🌙 Modern design

## Installation

1. Download the installer from the link above.
2. Open `MyBrowser-1.0.0-Setup.1.exe`.
3. Follow the installation steps.
4. Launch **MyBrowser**.
